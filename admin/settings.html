StudyBuddy Supplies — School Supplies Ordering System (Admin Panel)

This is a frontend-only demonstration. All data (products, stock, orders) is stored in your browser's localStorage.

Data Management

Reset all sample data to defaults. This clears products, stock, and orders from browser storage.

Important Notes

  • localStorage only works in a single browser — it does not sync across devices or users.
  • There is no secure admin login; this is a frontend demonstration only.
  • Real multi-user ordering and shared inventory require a backend and database.
  • Do not store real customer data here; it is saved locally in the browser.
